# Consultar Project Ignis

Fuente de verdad de textos y efectos, en este orden:

1. `{EDOPro}/repositories/delta-bagooska/script/official/c{id}.lua`
2. `{EDOPro}/script/official/c{id}.lua`
3. `cards.cdb` / `cards.delta.cdb` (nombre, tipo, ATK)
4. Fallback: GitHub `ProjectIgnis/CardScripts` (`official/c{id}.lua`)

El nombre inglés está en la segunda línea de comentario `--` del script Lua.
No reescribir scripts Lua. Solo leer ruling y efectos para documentar o rankear.
