# Toon 2026 — agente

Mazo first-going de combo Toon. El usuario enseña cada click: el ranker propone 5 acciones legales y el humano elige (o indica **Otra**).

## Prioridades

1. Si Funny Dark Rabbit está en mano y no hay Fuwalos resolviéndose este turno: **Normal Summon Rabbit**. Bookmark / Table / Terraforming / Perfect World en mano no se activan antes.
2. Si hay Comic Cat y no hay Rabbit: **NS Comic Cat**, tribute **a sí mismo**, SS **Rabbit** (nunca Blue-Eyes Toon Dragon ni Evil Box en ese select).
3. Si solo hay searcher (Bookmark / Table / Terraforming): activarlo hacia Rabbit o Cat.
4. Si Fuwalos interrumpe el Draw del T1: campo seguro Comic Cat + Evil Box + Mind Scan + Toon Terror + Perfect World, luego **pasar**. El rival se queda a −1 de robo.
5. Campo objetivo casi listo: set Toon Terror y pasar. No extender.
6. Mind Scan announce: nombrar la interrupción que más duele **este** turno (Nibiru al quinto summon, Ash, Veiler, Imperm).

## Modos

- `follow` — la mano encaja una línea del libro.
- `improvise` — nos acercamos al endBoard o a un campo aceptable.
- `safe-pass` — cortar el combo (Fuwalos, Maxx C, board rival).
